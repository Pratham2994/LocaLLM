# Repository structure

The order service is the code that README.md lists in its "Modules" table. Everything else is listed here.

| Folder | What it is | Used by the order service? |
|---|---|---|
| `depot/legacy/` | old versions, kept for the 2024 archive importer | no |
| `depot/experiments/` | drafts and notes | no |
| `depot/analytics/` | helpers for the monthly review | no |
| `depot/exporters/` | file exports for partners | no |
| `depot/integrations/` | adapters for outside systems | no |
| `depot/notifications/` | message texts | no |
| `depot/audit/` | change logs | no |
| `depot/scheduling/` | warehouse shifts | no |

README.md is the source of truth for the business rules. Notes and old code may say something else.
